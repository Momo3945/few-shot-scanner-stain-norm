# qualitative/ — legacy archive, do not move these files

This folder used to hold every qualitative image in the project, flat.
Most images have since moved into their owning ticket folder's `images/`
(e.g. `p1_16_source_fusion/images/`) — see the root `README.md` index.

**The files remaining here are intentionally kept in place**: they're
embedded by relative path (`qualitative/<file>.png`) directly in
`RESULTS_SUMMARY.md`'s markdown, which is treated as a stable, unedited
document. Moving or renaming anything in this folder would silently break
those embedded images. If you need one of these images elsewhere, copy it
— don't move it.
